隐私政策

本政策说明 TAO3 私人研究归档处理数据的用途、范围和管理方式。应用由持有人个人管理，仅供本人使用，不向其他人提供使用或授权服务。

生效日期：本页面正式发布之日。公开页面更新时将同步更新其内容。

1. 数据类别与用途

个人研究归档与检索会处理研究文件及其内容，包括归档 ZIP、JSON、Parquet、选中下载的研究文档、Google 文档导出的文本，以及提取的文本。相关文件信息可包括文件 ID、名称、大小、目录关系、时间、权限信息和校验值。

这些数据用于归档上传、名称检索、选中文档下载或导出、下载回读和一致性校验。原始资料、提取文本及相关工作记录可保存在 Codex Cloud 工作区，归档副本可保存在 Google Drive。检索范围可涉及授权账户可访问的 Drive 内容，并不只限于一个目录。

2. 授权范围与凭据

应用使用 Google OAuth 权限 https://www.googleapis.com/auth/drive这一权限允许查看、编辑、创建和删除授权账户中的全部 Google Drive 文件。个人归档与检索的使用目的，不会缩小权限本身的技术范围。

应用从云端运行环境读取 OAuth 配置，并与 Google 授权服务交换访问所需的令牌。运行与续传过程可能保留凭据或会话状态；本政策不作“所有凭据仅存在内存中”的保证。介绍网站不包含或收集这些凭据。

3. 运行平台与数据传输

Google 提供账户授权与 Drive 存储、读取和传输服务；OpenAI/Codex 提供应用运行及云端工作区。执行相应任务时，文件内容、元数据和相关运行信息会在这些平台中处理或传输。

平台处理方式受账户配置、所用服务及适用条款约束，可查阅 Google 隐私政策和 OpenAI 隐私政策；商业服务还可能适用其客户协议。本应用不额外承诺数据不用于模型训练、无第三方处理、端到端加密或已经通过安全审计。

4. 保存与删除

当前程序未设置统一的自动保留期限或自动删除期限。已保存的 Drive 文件、云工作区中的原始文件、提取文本和相关记录，需要由应用持有人分别管理和删除；平台自身的日志、备份及保留规则按相关服务规则执行。

停止某次任务、停止使用应用或撤销 Google 授权，不会自动删除先前保存的副本、文本、日志或凭据。本政策不保证这些数据在撤销后立即或于某个固定期限内全部删除。

5. 撤销 Google 授权

应用持有人可在 Google 账户的第三方连接页面管理并撤销 TAO3 的授权，以阻止应用继续依靠该授权访问 Google 数据。已保存的 Drive 和云工作区副本仍需分别处理。

6. 介绍网站的数据处理

网站只提供静态介绍和政策，不提供登录、脚本、追踪或表单，不接收 Drive 文件内容，也不自动加载外部资源。点击外部链接会进入相应平台，适用该平台的规则。

网站通过 GitHub Pages 提供访问时，GitHub 会出于安全目的记录和保存访问者的 IP 地址，即使访问者未登录 GitHub。详情见 GitHub Pages 数据收集说明及 GitHub 隐私声明。网页没有追踪脚本，不等于托管平台不记录访问日志。
